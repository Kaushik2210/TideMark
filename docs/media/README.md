# Tidemark media

Generated by `tidemark-media` (`pip install -e "pipeline[media]"`, then
`tidemark-media --out docs/media`) from `data/lakes.geojson` and `data/monthly/`. Nothing here is
illustrative: every shape and number comes from the pipeline outputs. All of it is an unvalidated
satellite estimate, not an official assessment.

Map colour shows which sensor supplied the month: blue = optical (Sentinel-2), green = fused
optical and radar, amber = radar (Sentinel-1). The dashed outline is the OpenStreetMap lake
outline. The "± ha" figure is a half-pixel edge bound, not a confidence interval.

Alt text for each image: "Two maps of <lake> showing mapped water extent in its largest and
smallest observed months, with an outline of the lake boundary" (before/after) and "Scatter plot
of monthly water area in hectares from 2016 to 2026, coloured by sensor, with a dashed line at the
mapped outline area" (trend).

Videos are H.264, 1280x720, 6 frames per second, one frame per month, map on the left and the
trend with a moving cursor on the right. Months with no usable scene show an empty map and the
text "no usable scene".
